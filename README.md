Simple ray-tracing project. This is a project I made for myself to discover and understand ray-tracing. No AI code agent or any kind of AI generated code has been used.

As I'm writing this there are only 2 possible props to fit in the scene, Rectangles and Spheres. All the objects are customizable and have color, reflectivity, lighting and roughness properties.
The FOV and resolution are customizable with no limitations
